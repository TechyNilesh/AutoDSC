\begin{abstract}
Data stream clustering faces unique challenges in dynamic environments where data distributions evolve continuously and computational resources are limited. While AutoML has transformed supervised learning, its application to unsupervised streaming tasks remains largely unexplored. Traditional clustering algorithms are sensitive to algorithm selection, hyperparameter configuration, and changes in data characteristics. We introduce AutoDSC (Automated Data Stream Clustering), a novel framework that automatically optimizes algorithm selection and hyperparameter tuning for real-time stream clustering. AutoDSC employs Population-Guided Stochastic Search Optimization (PGSSO), leveraging elite configurations to guide efficient parameter exploration while dynamically adjusting exploration rates based on performance feedback. The framework incorporates drift-aware adaptation for a proactive response to distributional changes and multi-objective evaluation with clustering validation indices for robust performance assessment. Our theoretical analysis establishes regret bounds for the optimization process. Comprehensive experiments demonstrate that AutoDSC achieves statistically significant improvements in clustering quality while maintaining computational efficiency compared to existing automated approaches.
\end{abstract}

\section{Introduction}

Automated Machine Learning (AutoML) has significantly advanced the accuracy and efficiency of machine learning workflows by automating tasks such as algorithm selection, hyperparameter optimization, and pipeline synthesis~\cite{hutter2019automated}. While AutoML has seen widespread adoption in supervised learning, its application to clustering remains comparatively less explored, mainly due to the absence of a universally applicable objective function for evaluation~\cite{poulakis2024survey}. Recent AutoML solutions for clustering include AutoML4Clust~\cite{Tschechlov2021AutoML4Clust}, AutoCluster~\cite{Liu2021AutoCluster}, cSmartML~\cite{ElShawi2021cSmartML}, ML2DAC~\cite{TrederTschechlov2023ML2DAC}, TPE-AutoClust~\cite{ElShawi2025TPEAutoClust}, and PoAC~\cite{daSilva2024PoAC}. These approaches address clustering challenges using various automated methodologies such as meta-learning, pipeline composition, and problem-specific heuristics.

However, with the increasing availability of streaming data from sources like Internet of Things (IoT) sensors, web traffic, and social media, traditional static AutoML approaches are insufficient~\cite{yang2022iot}. They cannot adapt to dynamic environments or process data in a single pass due to concept drift and memory limitations~\cite{bifet2018machine}. Existing online AutoML frameworks such as Online AutoML~\cite{celik2023online}, ASML~\cite{pmlr-v256-verma24a}, ChaCha~\cite{pmlr-v139-wu21d}, and Auto-Reg~\cite{verma2025auto-reg} primarily focus on supervised learning tasks. Meanwhile, unsupervised learning, particularly clustering, requires specialized AutoML solutions. At present, ConfStream~\cite{carnein2020confstream} and OnlineAutoClust~\cite{el2023onlineautoclust} represent the only established AutoML solutions for stream clustering. Nevertheless, they suffer from significant limitations. ConfStream relies on single clustering evaluation metrics, and OnlineAutoClust uses computationally intensive offline search methods, which are inefficient for real-time streaming scenarios. These limitations highlight the critical need for tailored AutoML solutions designed specifically for data stream clustering~\cite{bahri2021data}. This paper introduces AutoDSC (Automated Data Stream Clustering), a comprehensive AutoML framework for unsupervised data stream clustering. Our key contributions are:

\begin{itemize}
\item We propose AutoDSC, the first AutoML framework to unify elite-guided parameter optimization, concept drift detection, and multi-objective clustering evaluation in a single practical framework, introducing Population-Guided Stochastic Search Optimization (PGSSO) as a novel optimization mechanism that dynamically balances exploration and exploitation based on performance feedback in non-stationary streaming environments.

\item We establish formal regret bounds proving convergence for the optimization process and demonstrate efficient recovery after concept drift detection.

\item Through extensive experiments on synthetic and real-world data streams, we demonstrate that AutoDSC achieves statistically significant improvements in clustering quality while maintaining computational efficiency.
\end{itemize}

\section{Related Work}\label{sec:related}

Data stream clustering addresses the challenges of processing continuous, high-velocity data with limited computational resources~\cite{bifet2018machine,aggarwal2013data}. CluStream~\cite{aggarwal2003framework} pioneered the micro-cluster approach using pyramidal time frames to maintain summary statistics for scalable analysis. DenStream~\cite{Cao2006} advanced density-based clustering by introducing core-micro-clusters, potential micro-clusters, and outlier micro-clusters. DBSTREAM~\cite{Hahsler2016} enhanced density estimation by incorporating shared density graphs that explicitly model inter-micro-cluster relationships. This provides better resilience to concept drift compared to DenStream. For k-means-based approaches~\cite{Sculley2010}, mini-batch optimization combined with sparse projections has been developed to enable web-scale clustering with significantly reduced latency for real-time streaming applications. STREAMKMeans~\cite{montiel2021river} is an alternative version of the stream local search~\cite{OCallaghan2002} that replaces k-medians with incremental k-means.

Recent developments have focused on automated algorithm selection and hyperparameter optimization (CASH)~\cite{hutter2019automated} for stream clustering. ConfStream~\cite{carnein2020confstream} represents an early attempt at automated stream clustering configuration, using an ensemble of different clustering algorithms and configurations that dynamically adapt by evaluating clustering quality and sampling nearby new configurations proportionally to their performance using a normal distribution. However, ConfStream has significant limitations, including its reliance on a single Silhouette Width metric for quality assessment and limited parameter search capabilities. OnlineAutoClust~\cite{el2023onlineautoclust} developed an AutoML framework that combines Bayesian optimization with clustering ensembles, employing Tree-structured Parzen Estimators (TPE) for algorithm selection and hyperparameter tuning. However, OnlineAutoClust suffers from critical limitations, including dependence on offline tuning methods, high computational requirements, and sensitivity to allocated time budgets, which can lead to suboptimal pipeline selections during rapid concept drift. For concept drift detection, Dynamic Adapting Window Independence Drift Detection (DAWIDD)~\cite{hinder2020towards} addresses drift through non-parametric independence tests between random variables, providing robust detection across diverse drift types without assuming underlying models.

\section{Automated Data Stream Clustering}\label{sec:methodology}

We introduce Automated Data Stream Clustering (AutoDSC), a novel AutoML framework tailored for non-stationary data stream clustering. AutoDSC processes data in fixed-size windows. At the end of each window, AutoDSC evaluates clustering configurations using multiple normalized validation indices. The framework maintains an elite population of high-performing configurations to guide future parameter exploration via PGSSO. The framework adaptively balances exploration and exploitation through dynamic rate adjustment based on performance feedback. To quickly adapt to distributional changes, AutoDSC employs DAWIDD drift detection that triggers an internal state reset when concept drift is detected. Figure~\ref{fig:framework_overview} illustrates the high-level workflow of AutoDSC, while Algorithm~\ref{alg:autodsc} details the complete operational steps.

AutoDSC processes an infinite data stream $\mathcal{S} = \{x_1, x_2, \ldots, x_t, \ldots\}$ where each instance $x_t \in \mathbb{R}^d$ arrives at timestamp $t$ through a fixed-size windowing mechanism $W_t = \{x_{t-w+1}, x_{t-w+2}, \ldots, x_t\}$ with capacity $w$. The framework maintains a configuration population $\mathcal{A}_t$ containing multiple clustering algorithms with different hyperparameter settings, continuously adapts these configurations based on performance feedback, and provides real-time predictions using the best-performing configuration. The configuration space $\Theta = \prod_{i=1}^{|\mathcal{A}|} \Theta_i$ encompasses parameter spaces across all algorithms in the portfolio $\mathcal{A}$, where each configuration $\theta = (a_i, \phi_i)$ specifies both algorithm selection $a_i \in \mathcal{A}$ and hyperparameter values $\phi_i \in \Theta_i$. As each new data point arrives, the system performs incremental updates across all configurations:

\begin{equation}
\forall \theta_i \in \mathcal{A}_t: \quad M_i^{(t)} = \text{LearnOne}(M_i^{(t-1)}, x_t)
\end{equation}

where $M_i^{(t)}$ represents the model state of configuration $\theta_i$ at time $t$. When the window reaches capacity, the framework initiates evaluation and optimization operations.

AutoDSC first performs concept drift detection using DAWIDD~\cite{hinder2020towards} by extracting statistical features from each window $\mathbf{f}_t \leftarrow [\mu_{\|x\|}, \sigma_{\|x\|}, \min_{\|x\|}, \max_{\|x\|}, \text{median}_{\|x\|}, t]^T$. If significant distributional changes are detected (p-value $< \tau$), the system resets its internal state and increases exploration to rapidly adapt to the new data regime.

For performance assessment, AutoDSC evaluates clustering quality using three normalized clustering validation indices: Normalized Silhouette Coefficient $\text{NSC} = (1+\text{SC})/2$, Normalized Davies-Bouldin Index $\text{NDBI} = 1-\tanh(\text{DBI})$, and Normalized Calinski-Harabasz Index $\text{NCHI} = \tanh(\text{CHI})$, ensuring all metrics are bounded to $[0,1]$ where higher values indicate better clustering quality. The expected clustering quality for configuration $\theta$ at time $t$ is:

\begin{equation}
\mu_t(\theta) = \frac{1}{3}[\text{NSC} + \text{NDBI} + \text{NCHI}]
\end{equation}

AutoDSC dynamically adjusts exploration behavior based on performance improvement trends. The exploration rate $\alpha_t$ adapts based on relative improvement:

\begin{equation}
\Delta \mu_t = \mu_t(\theta^*_t) - \mu_{t-1}(\theta^*_{t-1})
\end{equation}

\begin{equation}
\alpha_{t+1} = \begin{cases}
\max(0.1, \alpha_t \cdot (1 - \gamma \cdot r_t)) & \text{if } \Delta \mu_t > 0 \\
\min(1.0, \alpha_t \cdot (1 + \gamma \cdot |r_t|)) & \text{if } \Delta \mu_t \leq 0
\end{cases}
\end{equation}

where $r_t$ represents normalized relative improvement and $\gamma$ controls adaptation rate. This mechanism decreases exploration when performance improves (favoring exploitation) and increases exploration when performance stagnates (encouraging broader search).

The framework employs \textbf{Population-Guided Stochastic Search Optimization (PGSSO)} (Algorithm~\ref{alg:pgsso}) to jointly optimize algorithm selection and hyperparameter tuning. PGSSO maintains an elite population $\mathcal{E}_t = \{(\theta_i, s_i)\}_{i=1}^{e}$ where each configuration $\theta_i = (a_i, \phi_i)$ pairs an algorithm choice with its hyperparameters, and $s_i = \mu_t(\theta_i)$ represents its performance score. By tracking which algorithm-hyperparameter combinations perform best, PGSSO naturally learns both which algorithms suit current data characteristics and their optimal settings. The elite population encodes this joint preference: frequently appearing algorithms indicate superior algorithmic choices, while their parameter distributions reveal effective settings. PGSSO adaptively balances exploration and exploitation through dynamic rate $\alpha_t$, computing statistical distributions over both algorithm selections (via frequencies) and their parameters (via means $\mu_j$ and variances $\sigma_j^2$), which together guide sampling of new promising algorithm-hyperparameter configurations.

PGSSO generates new configurations through probabilistic sampling:

\begin{equation}
\theta_{\text{new}} = \begin{cases}
\text{Elite-Guided}(\mathcal{E}_t) & \text{with probability } (1-\alpha_t) \\
\text{Random}(\Theta) & \text{with probability } \alpha_t
\end{cases}
\end{equation}

Elite-guided sampling first selects an algorithm based on elite frequencies, then samples its hyperparameters from learned distributions. Algorithm selection uses:

\begin{equation}
P(a = a_k) = \frac{\sum_{(\theta,s) \in \mathcal{E}_t} \mathbf{I}[a = a_k]}{|\mathcal{E}_t|}
\end{equation}

where $a_k \in \mathcal{A}$ represents available algorithms. Given selected algorithm $a_k$, numerical hyperparameters use Gaussian distributions from elite configurations of that algorithm:

\begin{equation}
\phi_j \sim \mathcal{N}(\mu_j, \sigma_j^2) \text{ where } \mu_j = \frac{1}{|\mathcal{E}_t^{a_k}|}\sum_{(\theta,s) \in \mathcal{E}_t^{a_k}} \phi_j
\end{equation}

and $\mathcal{E}_t^{a_k} = \{(\theta,s) \in \mathcal{E}_t : a = a_k\}$ contains elite configurations using algorithm $a_k$. Categorical hyperparameters similarly use frequency-based sampling within algorithm-specific elites. Figure~\ref{fig:parameter_sampling_visualization} illustrates this hierarchical sampling process.

\begin{figure}[!ht]
    \centering
    \includegraphics[width=1\linewidth]{images/parameter_sampling_visualization.png}
    \caption{Parameter Sampling Visualization.}
    \label{fig:parameter_sampling_visualization}
\end{figure}

Population diversity is maintained by computing configuration distances:

\begin{equation}
d(\theta_1, \theta_2) = \begin{cases}
1.0 & \text{if algorithms differ} \\
\frac{1}{|\mathcal{P}|} \sum_{p \in \mathcal{P}} d_p(\theta_1[p], \theta_2[p]) & \text{otherwise}
\end{cases}
\end{equation}

where $\mathcal{P}$ represents common parameters and $d_p$ computes normalized parameter-specific distances. New configurations are accepted only if they maintain a minimum pairwise diversity $\tau_{\text{div}}$ with existing population members.

Throughout the process, AutoDSC provides real-time clustering predictions using the incumbent (best) configuration:
\begin{equation}
\theta^*_t = \arg\max_{\theta_i \in \mathcal{A}_t} \mu_t(\theta_i)
\end{equation}

\subsection{Computational Complexity}

The framework's computational complexity scales efficiently with population size and window parameters. Per-instance processing requires $O(K \cdot C)$ operations where $K = |\mathcal{A}_t|$ and $C$ denotes average algorithm complexity. Window-end evaluation involves $O(K \cdot \rho w \cdot d)$ operations for evaluation on $\rho$-sampled data plus $O(K \cdot n_{\theta,t})$ for updating evaluation counts. Total per-window complexity is $O(K \cdot \rho w \cdot d + K^2)$, where $K^2$ accounts for population management. Space complexity is $O((K + e_{\max}) \cdot |\Theta| + w \cdot d)$.

\begin{algorithm}[!ht]
\caption{AutoDSC}
\label{alg:autodsc}
\textbf{Input:} Data stream $\mathcal{S} = \{x_1, x_2, \ldots\}$, $x_t \in \mathbb{R}^d$\\
\textbf{Parameter:} Window size $w$, Population size $K$, Diversity threshold $\tau_{\text{div}}$, Adaptation rate $\gamma$\\
\textbf{Output:} Cluster predictions $\{y_t\}_{t=1}^\infty$ using $\theta^*_t$
\begin{algorithmic}[1]
\State $e_{\max} \gets \lfloor K/2 \rfloor$, $\rho \gets 0.25$
\State $\mathcal{E}_0 \gets \emptyset$, $\alpha_0 \gets 0.5$
\State $\mathcal{A}_0 \gets \{\theta_i\}_{i=1}^K$ where $\theta_i \sim \text{Uniform}(\Theta)$
\State $W_0 \gets \emptyset$, $\theta^*_0 \gets \emptyset$
\State $\mu_{-1}(\theta^*_{-1}) \gets -\infty$
\For{each $x_t \in \mathcal{S}$}
    \State $W_t \gets W_{t-1} \cup \{x_t\}$
    \For{$\theta_i \in \mathcal{A}_t$}
        \State $M_i^{(t)} \gets \textsc{LearnOne}(M_i^{(t-1)}, x_t)$
    \EndFor
    \If{$|W_t| = w$}
        \State $\mathbf{f}_t \gets [\mu_{\|x\|}, \sigma_{\|x\|}, \min_{\|x\|}, \max_{\|x\|}, \text{median}_{\|x\|}, t]^T$
        \If{$\text{DAWIDD}(\mathbf{f}_t) = \text{drift}$}
            \State $\textsc{Reset}()$
            \State \textbf{continue}
        \EndIf
        \State $S_t \gets \textsc{Sample}(W_t, \rho)$
        \For{$\theta_i \in \mathcal{A}_t$}
            \State $L_i \gets \{\textsc{PredictOne}(M_i, s_j) : s_j \in S_t\}$
            \State $\mu_t(\theta_i) \gets \textsc{NormCVI}(S_t, L_i)$
            \State $n_{\theta_i,t} \gets n_{\theta_i,t-1} + 1$
        \EndFor
        \State $\mu_{\text{best}}^{(t)} \gets \max_i \mu_t(\theta_i)$
        \State $\alpha_{t+1} \gets \textsc{Adapt}(\alpha_t, \mu_{t-1}(\theta^*_{t-1}), \mu_{\text{best}}^{(t)}, \gamma)$
        \State $\mathcal{C}_{\text{new}} \gets \text{PGSSO}(\{(\theta_i, \mu_t(\theta_i))\}, \alpha_{t+1}, \Theta)$
        \State $\mathcal{A}_{t+1} \gets \textsc{SelectDiverse}(\mathcal{A}_t \cup \mathcal{C}_{\text{new}}, K, \tau_{\text{div}})$
        \State $\theta^*_t \gets \arg\max_{\theta_i \in \mathcal{A}_{t+1}} \mu_t(\theta_i)$
        \State $W_t \gets \emptyset$
    \EndIf
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[!ht]
\caption{PGSSO}
\label{alg:pgsso}
\textbf{Input:} Current configurations with scores $\{(\theta_i, s_i)\}$\\
\textbf{Parameter:} Exploration rate $\alpha \in [0,1]$, Parameter space $\Theta$\\
\textbf{Output:} New configuration set $\mathcal{C}_{\text{new}}$
\begin{algorithmic}[1]
\State $\mathcal{E} \gets \textsc{UpdateElitePopulation}(\{(\theta_i, s_i)\}, e_{\max})$
\State $\mathcal{E} \gets \textsc{UpdateParameterDistributions}(\mathcal{E})$
\State $\mathcal{C}_{\text{new}} \gets \emptyset$
\For{$j = 1$ to $n_{\text{gen}}$}
    \State $u \gets \text{Uniform}(0,1)$
    \If{$u > \alpha$}
        \State $\theta_{\text{new}} \gets \textsc{SampleFromElite}(\mathcal{E}, \Theta)$
    \Else
        \State $\theta_{\text{new}} \gets \textsc{RandomSample}(\Theta)$
    \EndIf
    \State $\mathcal{C}_{\text{new}} \gets \mathcal{C}_{\text{new}} \cup \{\theta_{\text{new}}\}$
\EndFor
\State \textbf{return} $\mathcal{C}_{\text{new}}$
\end{algorithmic}
\end{algorithm}

\section{Theoretical Analysis}\label{sec:theory}

We analyze AutoDSC using a phase-based approach where phases correspond to periods with fixed incumbent configurations. Let $j \in \{1,...,T/w\}$ index windows where $T/w$ represents the total number of windows given $T$ instances and window size $w$, and $t \in \{1,...,T\}$ index instances. We analyze AutoDSC's performance over $T/w$ windows divided into $M+1$ phases, where phase $m$ spans $N_m$ windows from window $j_m$ to $j_{m+1}-1$ with population $\mathcal{A}_{j_m}$ and incumbent configuration $\theta^*_{j_m}$. We track cumulative evaluations $n_{\theta,j}$ for each configuration $\theta$ across all windows up to window $j$. The expected clustering quality for configuration $\theta$ at window $j$ is defined as:

\begin{equation}
\mu_j(\theta) = \mathbb{E}[r_j(\theta)]
\end{equation}

where $r_j(\theta) \in [0,1]$ represents the instantaneous composite CVI score, and $\theta^{\text{opt}}_j = \arg\max_{\theta \in \Theta} \mu_j(\theta)$ denotes the optimal configuration at window $j$.

\textbf{Definition 1:} Let $p \in (0,1)$ denote the sample complexity parameter where estimation error decreases as $O(n^{-p})$ with $n$ samples (typically $p = 1/2$ for clustering).

\textbf{Definition 2:} Let $\text{comp}_\theta$ denote the computational complexity of evaluating configuration $\theta$ on one window.

\textbf{Assumption 1:} Rewards are bounded: $r_j(\theta) \in [0,1]$.

\textbf{Assumption 2:} Within stationary segments, $\mu_j(\theta)$ is $L$-Lipschitz in $\theta$.

\textbf{Assumption 3:} The optimal configuration $\theta^{\text{opt}}_j$ enters the population within $O(\log|\Theta|)$ windows after each concept drift.

Define confidence intervals:
\begin{equation}
\epsilon_{\theta,j} = O\left(\sqrt{\frac{\log(|\Theta|j/\delta)}{n_{\theta,j}}}\right)
\end{equation}
where $n_{\theta,j}$ is the number of evaluations of $\theta$ by window $j$ and $\delta \in (0,1)$ is a confidence parameter~\cite{auer2002finite}.

\textbf{Lemma 1 (PGSSO Selection Properties):} With probability $\geq 1-\delta$~\cite{cesa2006prediction}:

\emph{Claim 1:} If $\mu_j(\theta) - \mu_j(\theta^*_{j_m}) + 2\epsilon_{\theta,j} + 3\epsilon_{\theta^*_{j_m},j} > 0$, then PGSSO selects $\theta$ as the new incumbent $\theta^*_{j_{m+1}}$.

\emph{Claim 2:} When the incumbent switches from $\theta^*_{j_m}$ to $\theta^*_{j_{m+1}}$, we have $\mu_{j_{m+1}}(\theta^*_{j_m}) - \mu_{j_{m+1}}(\theta^*_{j_{m+1}}) > \epsilon_{\theta^*_{j_m},j_{m+1}}$.

\emph{Claim 3:} If $\mu_j(\theta) < \mu_j(\theta^*_{j_m})$, then $\theta$ will not replace $\theta^*_{j_m}$ as the incumbent.

\textbf{Lemma 2 (Drift Detection):} DAWIDD detects concept drift within $O(\log T)$ windows with probability $\geq 1-\delta$, triggering population reset.

\textbf{Lemma 3 (Adaptive Exploration):} The adaptive exploration mechanism in PGSSO, which adjusts $\alpha_j$ based on performance trends, improves the expected regret constants by a factor of $(1+\gamma)^{-1}$ compared to fixed exploration, where $\gamma$ is the adaptation rate.

\textbf{Proposition 1 (Window Regret):} With sample complexity parameter $p$ and properly set confidence intervals, AutoDSC achieves:

\begin{align}
&\sum_{m=0}^M \sum_{j=j_m}^{j_{m+1}-1} \left(\mu_j(\theta^{\text{opt}}_j) - \mu_j(\theta^*_{j_m})\right) \nonumber\\
&= \tilde{O}\left(\frac{K \cdot \text{comp}_{\theta^{\text{opt}}} \cdot (T/w)^p}{p(1+\gamma)} + \text{comp}_{\theta^*} (T/w)^{\frac{1}{2-p}}\right)
\end{align}

where $K = \max_j |\mathcal{A}_j|$ is the maximum population size.

\textbf{Proof Sketch:} The bound decomposes regret into two terms: (i) regret from suboptimal population sampling, bounded by PGSSO's exploration guarantee with adaptive exploration reducing the constant by $(1+\gamma)^{-1}$, and (ii) regret from incumbent updates. Lemma 1 ensures incumbent switches occur only when sufficiently beneficial, limiting the number of phases $M = O((T/w)^{\frac{1-p}{2-p}})$. The confidence intervals shrink as $O(n_{\theta,j}^{-1/2})$, yielding the stated bounds~\cite{auer2002finite}.

\textbf{Theorem 1 (Total Regret):} Under the same conditions, AutoDSC achieves instance-level regret:
\begin{align}
&\sum_{t=1}^T \left(\mu_{\lceil t/w \rceil}(\theta^{\text{opt}}_{\lceil t/w \rceil}) - \mu_{\lceil t/w \rceil}(\theta^*_{\lceil t/w \rceil})\right) \nonumber\\
&= \tilde{O}\left(\frac{K \cdot \text{comp}_{\theta^{\text{opt}}} \cdot T^p}{(1+\gamma)} + \text{comp}_{\theta^*} T^{\frac{1}{2-p}}\right)
\end{align}

\textbf{Proof Sketch:} Since clustering quality is constant within windows, summing over $T$ instances with window-level quality yields:
\begin{equation}
\sum_{t=1}^T (\cdot) = \sum_{j=1}^{T/w} w \cdot (\mu_j(\theta^{\text{opt}}_j) - \mu_j(\theta^*_j))
\end{equation}
Applying Proposition 1 and noting $w$ is constant gives the result.

\textbf{Corollary 1 (Drift Recovery):} After concept drift, AutoDSC recovers $\epsilon$-optimal performance within $O(\log|\Theta|/\epsilon^2)$ windows.

For $p = 1/2$, the regret bound becomes $\tilde{O}(\sqrt{T})$, matching optimal rates for non-stationary bandits with concept drift~\cite{besbes2014stochastic}.

\textbf{Evaluation Protocol:} All experiments use prequential evaluation (test-then-train)~\cite{bifet2018machine} with 10 independent runs using random seeds 1-10 to account for stochastic variability. Performance is measured using the non-adjusted Rand Index~\cite{rand1971objective}, where ground truth labels are used solely for evaluation, not training or model selection. We also record execution time (minutes) and memory usage (MB) to assess computational efficiency. Statistical significance is assessed using the Friedman test followed by the Nemenyi post-hoc test~\cite{demvsar2006statistical} with $\alpha = 0.10$.

\textbf{Baseline Methods:} We compare AutoDSC against four baseline approaches. \textit{Default(Best)} represents the best-performing algorithm among CluStream, DenStream, DBSTREAM, KMeans, and STREAMKMeans using default parameters, selected per dataset based on mean Rand Index across 10 runs. This approach reflects common practice among non-expert users who apply standard algorithms without extensive hyperparameter tuning. \textit{ConfStream}~\cite{carnein2020confstream} and \textit{OnlineAutoClust}~\cite{el2023onlineautoclust} represent established AutoML approaches for stream clustering that optimize hyperparameters within the same parameter ranges. \textit{RandomSearch}~\cite{bergstra2012random} operates similarly to AutoDSC's framework structure but uses purely random sampling for algorithm selection and hyperparameter configuration generation, providing a direct comparison to our guided optimization approach.

\textbf{Configuration:} AutoDSC uses the parameters specified in the methodology: population size 20, window size 1000, exploration rate 0.5, adaptation rate $\gamma=0.1$, and diversity threshold 0.1. For fair comparison, following standard AutoML benchmarking practices~\cite{gijsbers2024amlb}, all methods optimize hyperparameters within identical search spaces as specified in Table~\ref{tab:hyperparameters}. Other baseline-specific parameters remain as reported in their original papers.

All experiments were conducted on AMD EPYC 7702 64-core servers with 1TB RAM, utilizing parallelization for computational efficiency. All clustering algorithms were implemented using the River Python library~\cite{montiel2021river} for online machine learning.

\section{Discussion}\label{sec:discussion}
AutoDSC represents a significant advancement in AutoML for streaming environments through several key innovations. Our multi-objective evaluation strategy, combining three normalized clustering validation indices, provides robust performance assessment compared to single-metric approaches used in ConfStream (Silhouette Width only) and OnlineAutoClust's ensemble voting. This prevents optimization convergence to configurations that excel in one aspect while failing catastrophically in others~\cite{arbelaitz2013extensive,liu2010understanding}. The PGSSO outperforms existing methods by dynamically adjusting exploration rates based on performance trends, enabling rapid parameter space exploration after concept drift while efficiently exploiting successful configurations during stable periods, contrasting with ConfStream's fixed ensemble strategy and OnlineAutoClust's computationally intensive offline Bayesian optimization~\cite{hinder2020towards}. While our current evaluation focuses on tabular data streams with numerical and categorical features, extensions to high-dimensional sparse text streams, multi-modal event streams, or image-based data would require domain-specific clustering algorithms beyond this scope. These novel contributions collectively bridge the gap between traditional AutoML approaches and the dynamic requirements of deploying real-time streaming applications in IoT, sensor networks, and analytics platforms, where manual configuration is impractical~\cite{bahri2021data}.

\section{Conclusion and Future Work}\label{sec:conclusion_and_future}

We presented AutoDSC, a novel AutoML framework for adaptive data stream clustering that unifies algorithm selection, hyperparameter optimization, and concept drift adaptation. Extensive experiments across diverse datasets demonstrate AutoDSC's statistical significance, achieving the highest average Rand Index while executing faster than existing frameworks. The framework is supported by theoretical analysis providing convergence guarantees in non-stationary environments. Future research directions include extending AutoDSC to semi-supervised settings, multi-task clustering, and advanced multi-objective optimization techniques to balance trade-offs such as accuracy, efficiency, and robustness in dynamic settings.

\subsection{Sensitivity Analysis}\label{appendix:sensitivity}

Comprehensive sensitivity analysis conducted across all twelve datasets evaluated AutoDSC's robustness across systematic hyperparameter variations, establishing optimal configuration ranges essential for practical deployment in diverse streaming environments. Results are averaged across real-world and synthetic streams to ensure generalizability. The diversity threshold parameter exhibits optimal performance within the range $\tau_{\text{div}} = 0.15-0.25$, achieving peak clustering quality (Figure~\ref{fig:sensitivity_diversity}), with lower threshold values causing premature convergence by allowing similar configurations to dominate the population, while higher values over-restrict configuration selection and reduce optimization efficiency. Adaptation rate analysis reveals $\gamma = 0.1$ as the optimal setting (Figure~\ref{fig:sensitivity_gamma}), as lower adaptation rates, such as $\gamma = 0.01$, result in sluggish responses to changing performance trends. In comparison, higher rates, including $\gamma \geq 0.2$ introduce excessive volatility that destabilizes the optimization process. Window size evaluation identifies the optimal range as $w = 1000-1500$, achieving consistent performance levels (Figure~\ref{fig:sensitivity_window}), with smaller window sizes providing insufficient data for reliable clustering evaluation and introducing noise through excessive optimization frequency, while larger windows delay adaptation responses to concept drift events. Population size demonstrates the most dramatic performance variation across tested values, with a clear optimum at $K = 20$ (Figure~\ref{fig:sensitivity_population}), as smaller population sizes limit exploration coverage of the parameter space, while larger sizes introduce computational overhead and complicate elite population management. These findings establish robust optimal configuration guidelines for practical AutoDSC deployment: diversity threshold $\tau_{\text{div}} = 0.1$, adaptation rate $\gamma = 0.1$, window size $w = 1000$, and population size $K = 20$, demonstrating that AutoDSC exhibits stable performance within reasonable hyperparameter ranges while showing graceful degradation outside optimal regions, with population size representing the most critical parameter requiring careful tuning for optimal performance.

\subsection{Drift Detection Method Selection}\label{appendix:drift_detection}

We adopt the Dynamic Adapting Window Independence Drift Detection (DAWIDD) method~\cite{hinder2020towards} for detecting concept drift in AutoDSC. Unlike traditional loss-based drift detectors such as DDM, EDDM, and ADWIN that rely on classification error as a proxy for distributional change, DAWIDD provides a non-parametric, model-free approach by reformulating drift detection as an independence test between data observations and their timestamps. This theoretical foundation, grounded in the equivalence between concept drift and statistical dependency of random variables, enables DAWIDD to detect diverse drift characteristics including both gradual and abrupt changes without requiring assumptions about the underlying drift type. As shown in Figure~\ref{fig:drift_heatmap}, DAWIDD consistently achieves superior True Positive (TP) detection rates on benchmark datasets common to both studies: obtaining TP values of 1.70 on Hyperplane, 1.30 on Random (RBF), and 1.40 on Forest Cover—substantially outperforming HDDDM, EDDM, DDM, and ADWIN which frequently achieve TP values below 0.5 on these same datasets. This superior detection capability, combined with its model-free nature, makes DAWIDD particularly well-suited for AutoDSC where the underlying clustering model is automatically selected and drift characteristics are unknown a priori.
